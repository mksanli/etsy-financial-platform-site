Clearer financial decisions for Etsy sellers.

We are developing a web-based financial analytics and decision-support platform to help Etsy shop owners understand sales performance, costs, and profitability.

What we are building

Sales & order insights

Organize available shop, order, transaction, and listing information into useful financial views.

Profitability analysis

Combine available Etsy data with seller-provided product, shipping, and other costs to estimate financial results.

Pricing decision support

Explore cost-aware pricing and margin scenarios to support better-informed seller decisions.

How Etsy connection is intended to work

Shop owners will explicitly authorize access using Etsy OAuth 2.0. The planned integration is read-only: it is intended to retrieve data available through the Etsy Open API for financial reporting and analysis. It will not create or edit listings, send customer emails, or change shop information.

Actual data availability and API permissions are subject to Etsy's API capabilities and authorization. Seller-provided costs will supplement marketplace data.

Current status

This product is in development. An initial private pilot with a small group of authorized users is planned. Public registration and paid subscriptions are not currently offered through this website. The longer-term goal is a commercial subscription service.
