Privacy Policy

Last updated: November 16, 2026

This page describes the intended data practices for the Seller Financial Intelligence project, a private, non-commercial financial reporting and decision-support tool intended solely for its developer’s own Etsy shop. The application is currently under development; this website is informational and does not currently provide Etsy account connection or user registration.

Contact

For privacy questions or requests, contact koksalsanli@gmail.com.

Information collected by this website

This static informational website does not contain a registration form or request Etsy account credentials. If you contact us by email, we receive the information you choose to send. GitHub Pages, which hosts this site, may process technical request information according to its own policies.

Planned application data processing

If the personal MVP is enabled, I intend to authorize my own Etsy shop through OAuth 2.0 and access available read-only shop data, including orders, transactions, payments, fees, and listings, for my own financial reporting. I will supplement it with my own product and shipping cost records. This website does not request Etsy passwords or API keys.

Purpose and sharing

The intended purpose is to review financial performance, reconcile records, and evaluate pricing for my own Etsy shop. The MVP is not offered to third-party users. I do not intend to sell Etsy seller or buyer information. Any external infrastructure providers and their roles will be documented before live data processing begins.

Retention, security, and your choices

Before connecting the MVP to live Etsy data, this policy will be updated to reflect actual data storage, retention, security measures, service providers, access revocation, deletion procedures, and applicable privacy rights. Contact me using the email above with questions.

Changes

We may update this policy as development progresses. The latest version and its update date will be published here.
