Under development · Personal, non-commercial MVP

Financial clarity for my Etsy shop.

I am developing a private, non-commercial financial reporting and decision-support tool solely for my own Etsy shop to review sales performance, costs, and profitability.

What I am building

Sales & order insights

Review available order, transaction, and listing information from my own shop.

Profitability analysis

Combine available Etsy data with my own product, shipping, and other cost records to evaluate profitability.

Pricing decision support

Evaluate pricing and margin scenarios for my own shop.

Planned Etsy API connection

I plan to authorize access to my own Etsy shop using OAuth 2.0. The integration is intended to read available Etsy Open API data for my own financial reporting and analysis. It will not create or edit listings, send customer emails, or change shop information.

Actual data availability and API permissions are subject to Etsy's API capabilities and authorization. My own cost records will supplement marketplace data.

Current status

This is a personal, non-commercial MVP under development for use only with my own Etsy shop. It is not offered to other users, and there is no public registration, subscription service, or fee for access.
