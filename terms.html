About this project

Seller Financial Intelligence is a private, non-commercial minimum viable product (MVP) being developed solely to support financial reporting and decision-making for the developer's own Etsy shop. It is not currently available to other users, and no public registration or paid service is offered.

Intended use

The planned tool will use authorized, read-only Etsy Open API access to review available shop sales, orders, transactions, fees, payments, and listings, together with the developer's own cost records. Access and functionality remain subject to Etsy's API terms, permissions, and policies. The tool will not modify Etsy shop data or send customer emails.
